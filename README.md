# Reniel Villareal — Clean Portfolio

A responsive portfolio website made with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, colors, responsive styles, and hover effects
- `script.js` — mobile navigation, theme toggle, active navigation, and contact email behavior
- `image/profile.png` — place your professional portrait here
- `resume.pdf` — place your resume here if you want the download links to work

## Run locally
1. Extract the ZIP file.
2. Open the `reniel_portfolio_clean` folder in Visual Studio Code.
3. Put your picture inside the `image` folder and name it exactly `profile.png`.
4. Put your resume PDF in the main folder and name it exactly `resume.pdf`.
5. Open `index.html` with VS Code Live Server, or double-click it to open in a browser.

## Important
- Keep `index.html`, `style.css`, and `script.js` together in the main folder.
- Keep your portrait at `image/profile.png` (the path is case-sensitive when published online).
- Replace sample GitHub and social links with your own profile URLs before publishing.
- The contact form opens the visitor's email application; it does not send messages through a website server.
